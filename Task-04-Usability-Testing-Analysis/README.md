# Task 04: Usability Testing and Analysis

A usability evaluation of the Canara Engineering College website conducted through task-based testing sessions with five participants to analyze navigation efficiency, information architecture, and user drop-off points.

##  Evaluation Overview
- Digital Product: Canara Engineering College Website
- Evaluation Method: Task-Based Usability Testing
- Sample Size: 5 Participants (Students & Peers)
- Session Duration: 10–15 Minutes per user

---

##  Test Scenarios

| T1| Find the courses/programs offered by the college | Navigation path & academic taxonomy |

| T2| Locate admission requirements and procedures | Discoverability of admissions portal |

| T3| Find official college contact details | Visibility of primary contact access points |

| T4 | Access recent news, events, and announcements | Ease of locating time-sensitive updates |



##  Observations & Usability Metrics

### Observation Log
- T1 (Courses): 100% success rate (Avg: ~35s). Found with minimal hesitation across desktop and mobile.

- T2 (Admissions): 80% success rate (Avg: ~53s). Users hesitated navigating multi-tiered menu options.
  
- T3 (Contact Info): 60% success rate (Avg: ~56s). Highest friction point; multiple participants struggled without explicit footer/header prominence.

- T4 (News/Events): 80% success rate (Avg: ~50s). Users required deeper scrolling to distinguish active notices from static banners.



##  Prioritized Design Recommendations
1. Prominent Contact Access: Introduce a sticky global header button and a high-contrast footer link for instant access to contact details.
2. Simplified Admissions Pathway: Elevate the Admissions CTA to primary visual hierarchy on the landing viewport.
3. Streamlined Navigation Labels: Reduce menu depth and group academic offerings under unified categorical tags.
4. Dedicated Events Hub: Provide a distinct card carousel for live notices to prevent critical deadlines from blending into layout images.
